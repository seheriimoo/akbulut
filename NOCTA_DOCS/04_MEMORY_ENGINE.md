# NOCTA MEMORY ENGINE

---

## Purpose

The Memory Engine defines how Nocta remembers, updates, and applies user information across conversations.

Its purpose is not simply to store information.

Its purpose is to build a deeper understanding of the user over time, allowing every conversation to become more personal, relevant, and emotionally accurate.

The Memory Engine works alongside the Cognitive Architecture and Conversation Engine to ensure that Nocta responds not only to the user's current message, but also to the broader context of who they are, what they have experienced, and what matters to them.

Rather than treating every conversation as a new beginning, the Memory Engine enables continuity, helping users feel genuinely remembered instead of repeatedly reintroduced.

Every memory should improve understanding.

No memory should exist without a meaningful purpose.

---

## Memory Philosophy

Nocta remembers users in order to understand them more deeply, not to accumulate information.

Memory exists to reduce repetition, strengthen continuity, and create conversations that feel increasingly personal over time.

Every remembered detail should have a clear purpose within the user's experience.

The Memory Engine prioritizes meaningful patterns over isolated facts.

Rather than remembering everything, Nocta remembers what helps it better support the user emotionally and cognitively.

Memory should always serve understanding.

It should never exist simply because it can.

---

## Memory Types

The Memory Engine organizes user information into different categories based on its purpose and long-term value.

### Identity Memory

Stable information about the user, such as their preferred name, language, or long-term preferences.

### Emotional Memory

Recurring emotional patterns, common emotional triggers, and the user's typical emotional responses.

### Cognitive Memory

Recurring thinking patterns, mental habits, common worries, and reasoning styles that influence conversations.

### Preference Memory

User preferences related to conversation style, audio experiences, communication tone, and interaction choices.

### Progress Memory

Important milestones, personal achievements, ongoing goals, and meaningful changes over time.

### Context Memory

Relevant information from previous conversations that helps maintain continuity without requiring the user to repeat themselves.

Each memory type serves a specific purpose.

No memory should be stored unless it improves future understanding or personalization.

---

## Memory Lifecycle

Memory is not static.

Every memory follows a continuous lifecycle that ensures it remains accurate, relevant, and useful over time.

### Creation

A memory is created only when information is meaningful, recurring, or likely to improve future conversations.

### Reinforcement

When the same pattern, preference, or experience appears consistently across conversations, the memory becomes stronger and more reliable.

### Update

If new information replaces or changes an existing understanding, the memory is updated to reflect the user's current reality.

### Fading

Information that is no longer relevant or has not been reinforced over time gradually loses importance.

### Removal

Memories that no longer improve understanding or personalization should be removed rather than permanently retained.

The Memory Engine continuously prioritizes relevance over quantity.

Its objective is not to remember the most information.

Its objective is to remember the right information.

---

## Memory Usage Principles

The Memory Engine supports conversations by providing relevant context, not by dominating the interaction.

Memory should always enhance the current conversation without distracting from the user's present needs.

When appropriate, Nocta naturally incorporates remembered information to create continuity, acknowledge progress, or recognize recurring patterns.

Remembered information should never feel intrusive, unexpected, or unnecessarily repeated.

The Memory Engine should prioritize the most relevant memories based on the user's current emotional state and conversational context.

Current understanding always takes precedence over past memories.

Memory exists to support the conversation, not to control it.

---

## Memory Boundaries

The Memory Engine remembers only information that improves future understanding and personalization.

It does not retain information simply because it was mentioned.

Nocta avoids storing unnecessary, temporary, or irrelevant details that do not contribute to future conversations.

The Memory Engine respects user privacy and prioritizes meaningful understanding over excessive retention.

Users should always feel that Nocta remembers what matters—not everything they have ever said.

Memory should never create discomfort, surprise, or the feeling of being excessively observed.

These boundaries ensure that memory remains supportive, respectful, and aligned with Nocta's purpose.

---

## Memory Quality Standards

Every memory used by Nocta should meet the same quality standards.

A high-quality memory should:

- Improve future understanding of the user.
- Be relevant to the user's long-term experience.
- Support more natural and personalized conversations.
- Remain accurate and up to date.
- Respect the user's privacy and emotional comfort.
- Avoid unnecessary or excessive retention.
- Strengthen continuity without feeling intrusive.
- Prioritize meaningful patterns over isolated facts.
- Adapt as the user grows and changes over time.

Every remembered detail should make the user feel more understood—not more observed.
