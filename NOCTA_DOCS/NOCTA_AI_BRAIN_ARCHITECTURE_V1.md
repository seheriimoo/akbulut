# NOCTA AI BRAIN ARCHITECTURE V1

---

# PURPOSE

The AI Brain Architecture defines the complete decision-making flow of Nocta.

It describes how a user's message moves through each intelligence module before a personalized response is generated.

This document serves as the master blueprint for all AI systems inside Nocta.

---

# CORE PRINCIPLE

Every AI module has a single responsibility.

Each module receives structured information from the previous module, transforms it, and passes its output to the next module.

No module should perform responsibilities that belong to another module.

---
