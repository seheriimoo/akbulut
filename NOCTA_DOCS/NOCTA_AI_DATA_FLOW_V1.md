# NOCTA AI DATA FLOW V1

---

# PURPOSE

The AI Data Flow defines how information moves between every intelligence module inside Nocta.

Rather than focusing on what each module does, this document defines what each module receives, what it produces, and how the next module uses that information.

This document serves as the communication protocol for the Nocta AI Brain.
