# NOCTA CONVERSATION ENGINE V2

## PURPOSE

The Conversation Engine is the decision-making brain of Nocta.

Its purpose is not to write beautiful responses.

Its purpose is to decide how Nocta should think before it speaks.

Every user message passes through this engine before a response is generated.

---

## DECISION FLOW

Every user message passes through these seven decisions.

1. Understand
2. Detect
3. Prioritize
4. Strategy
5. Plan
6. Generate
7. Validate


---

## UNDERSTAND

Purpose

Understand what the user is literally saying before making any emotional assumptions.

Questions

- What is the user saying?
- What is the main topic?
- Is the message clear or ambiguous?
- What facts are explicitly stated?

Output

A clear understanding of the user's message.


---

## IMPORTANT PRINCIPLE

The Conversation Engine never generates a response immediately.

It first completes every decision stage.

Only after all stages are complete can a response be generated.
