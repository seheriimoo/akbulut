# NOCTA AUDIO INTELLIGENCE V2

## PURPOSE

This document defines how Nocta selects the most appropriate audio experience and audio session.

Audio selection begins after the user's emotional state and sleep profile have been identified.

The goal is not to assign one fixed sound to one category.

The goal is to translate the user's experience tonight into the most supportive transition toward sleep.

---

# AUDIO SELECTION FLOW

User Message
↓
State Detection
↓
Playbook Selection
↓
Sleep Profile Selection
↓
Audio Experience Selection
↓
Audio Session Selection

---

# CORE PRINCIPLE

States describe what the user is experiencing.

Sleep profiles define what the user needs in order to move toward rest.

Audio experience types define the psychological function of the session.

Audio sessions deliver that function through voice, pacing, sound and atmosphere.

Audio should therefore be selected through the sleep profile, not through category keywords alone.

---

# SELECTION RULES

Nocta should:

- Use the dominant emotional state detected in the conversation
- Select the corresponding sleep profile
- Identify the psychological function needed tonight
- Select an audio session that supports that function
- Preserve continuity between the final AI message and the audio experience

Nocta should not:

- Select audio from a single keyword
- Treat all users within one category identically
- Choose sound environments without considering emotional need
- Create an abrupt transition between conversation and audio
- claim that the selected session will solve the user's problem

# AUDIO EXPERIENCE TYPES

## 01 — FUTURE RELEASE

Purpose:

Reduce future-focused urgency.

Supports:

- Uncertainty
- Upcoming events
- What-if thinking
- Anticipatory anxiety
- Mental preparation loops

---

## 02 — MENTAL QUIETING

Purpose:

Reduce cognitive activity and create space between thoughts.

Supports:

- Racing thoughts
- Repetitive analysis
- Mental loops
- Cognitive overload
- Difficulty switching off

---

## 03 — LETTING GO

Purpose:

Loosen emotional and mental attachment to what cannot be resolved tonight.

Supports:

- Relationship rumination
- Searching for closure
- Replaying conversations
- Waiting for answers
- Difficulty emotionally disengaging

---

## 04 — SAFETY & COMFORT

Purpose:

Create a sense of emotional safety, presence and support.

Supports:

- Loneliness
- Feeling disconnected
- Feeling unseen
- Emotional vulnerability
- Nighttime isolation

---

## 05 — DEEP REST

Purpose:

Support physical and mental decompression after sustained effort.

Supports:

- Work stress
- Burnout
- Exhaustion
- Responsibility overload
- Running on empty

---

## 06 — EMOTIONAL RELEASE

Purpose:

Reduce emotional weight without forcing the user to process or resolve everything.

Supports:

- Sadness
- Regret
- Grief
- Heartbreak
- General emotional pain

# AUDIO SESSION SELECTION

Each audio experience type may contain multiple audio sessions.

The selected session may vary according to:

- Emotional intensity
- Mental activity level
- Need for safety
- Need for release
- Need for grounding
- Preferred sound environment
- Previous session history

A sleep profile defines the required direction.

The audio session defines tonight's specific delivery.

---

# CONTINUITY RULE

The final conversation message and the selected audio session must feel like one continuous experience.

The sleep transition should prepare the user for the psychological function of the audio.

Example:

Quiet The Mind
↓
The final message reduces the need to keep thinking
↓
Mental Quieting session continues the slowing process

---

# SUCCESS CRITERIA

The audio selection is successful when:

- It matches the user's dominant need tonight
- It continues the emotional direction of the conversation
- It reduces urgency rather than introducing new stimulation
- It does not require the user's problem to be solved
- It helps the user carry less into sleep

---

# CORE RULE

Nocta does not select audio merely because of what the user is talking about.

Nocta selects audio according to what the user needs in order to rest tonight.
