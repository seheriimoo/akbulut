# NOCTA CATEGORY DETECTION V1

## PURPOSE

Determine which psychological category is most relevant to the user's message.

The system should identify the dominant emotional pattern, not individual keywords.

---

## DETECTION PRINCIPLE

Category detection should not rely on keywords alone.

Keywords are signals.

The primary objective is to identify the dominant emotional pattern behind the message.

The system should prioritize:

1. Emotional Pattern
2. User State
3. Context
4. Keywords

Keywords should support classification.

Keywords should not determine classification alone.
