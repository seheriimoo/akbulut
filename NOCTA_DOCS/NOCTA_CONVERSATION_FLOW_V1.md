# NOCTA CONVERSATION FLOW V1

## PURPOSE

This document defines the ideal conversation length and user journey inside Nocta.

The goal is not prolonged engagement.

The goal is sleep transition.

---

# CORE PRINCIPLE

Every message should reduce mental activity.

Every response should move the user closer to rest.

The conversation should end before it becomes another thing to think about.

---

# STANDARD FLOW

User Message
↓
AI Response 01
↓
AI Response 02
↓
AI Response 03
↓
Sleep Transition
↓
Audio Session

---

# RESPONSE 01

Purpose:

Observe

Acknowledge the user's experience.

Help the user feel understood.

Do not solve.

Do not advise.

---

# RESPONSE 02

Purpose:

Narrow

Reduce complexity.

Identify the most important emotional thread.

Move attention away from everything.

Toward one thing.

---

# RESPONSE 03

Purpose:

Reframe + Release

Offer a new perspective.

Reduce pressure.

Create permission to stop thinking.

Prepare for sleep transition.

---

# SLEEP TRANSITION

Purpose:

Move the user from conversation into rest.

The conversation should naturally close.

The audio session becomes the next step.

---

# SUCCESS CRITERIA

The user feels:

- Understood
- Less pressured
- Less mentally activated
- Ready for rest
