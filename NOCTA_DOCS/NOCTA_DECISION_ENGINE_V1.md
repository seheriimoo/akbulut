# NOCTA DECISION ENGINE V1

## PURPOSE

This document defines how Nocta makes decisions.

The purpose is to move from a user message to the correct response and sleep transition path.

---

# DECISION FLOW

User Message
↓
Category Detection
↓
Insight Selection
↓
Mental State Detection
↓
Response Construction
↓
Sleep Transition
↓
Audio Selection

---

# STAGE 01 — CATEGORY DETECTION

Purpose:

Identify the primary emotional category behind the user's message.

Possible Categories:

- Overthinking
- Future Anxiety
- Relationship
- Loneliness
- Emotional Pain
- Work Stress

Output:

Primary Category

---

# STAGE 02 — INSIGHT SELECTION

Purpose:

Select the most relevant insight within the category.

Output:

Primary Insight

Golden Reframe

---

# STAGE 03 — MENTAL STATE DETECTION

Purpose:

Identify the user's underlying mental state.

Possible Mental States:

- Mental Activation
- Control Seeking
- Emotional Weight
- Disconnection
- Exhaustion
- Future Pressure

Output:

Primary Mental State

Recommended Audio Experience

---

# STAGE 04 — RESPONSE CONSTRUCTION

Purpose:

Generate response using:

Observe
↓
Narrow
↓
Reframe
↓
Release

Output:

Nocta Response

---

# STAGE 05 — SLEEP TRANSITION

Purpose:

Determine whether the user is ready to move toward rest.

Output:

Transition Ready

---

# STAGE 06 — AUDIO SELECTION

Purpose:

Select the most appropriate audio experience.

Audio Types:

- Mental Quieting
- Letting Go
- Emotional Release
- Safety & Comfort
- Deep Rest
- Future Release

Output:

Audio Experience
