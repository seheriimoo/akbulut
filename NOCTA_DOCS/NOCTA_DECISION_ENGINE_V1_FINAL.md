# NOCTA DECISION ENGINE V1

## PURPOSE

This document defines how Nocta makes decisions.

The purpose is to move from a user message to the correct response and sleep transition path.

---

# DECISION FLOW

User Message
↓
Category Detection
↓
Insight Selection
↓
Response Construction
↓
Sleep Transition
↓
Audio Selection

---

# STAGE 01 — CATEGORY DETECTION

Purpose:

Identify the primary emotional category behind the user's message.

Possible Categories:

- Overthinking
- Future Anxiety
- Relationship
- Loneliness
- Emotional Pain
- Work Stress

---

# STAGE 02 — INSIGHT SELECTION

Purpose:

Select the most relevant insight within the category.

Input:

Category

Output:

Primary Insight
Secondary Insight
Reframe Direction

---

# STAGE 03 — RESPONSE CONSTRUCTION

Purpose:

Generate response using:

Observe
↓
Narrow
↓
Reframe
↓
Release

---

# STAGE 04 — SLEEP TRANSITION

Purpose:

Determine whether the user is ready to move toward rest.

---

# STAGE 05 — AUDIO SELECTION

Purpose:

Select the most appropriate audio experience based on the user's state.
