# Nocta Emotional Conversation Families v1

## Version

1.0

## Status

Taxonomy Design — Canonical

Effective Date: 2026-08-07

This document defines **Emotional Conversation Families**: a taxonomy of nighttime emotional categories and which already-allowed Blueprint shapes they naturally use.

It does **not** change:

- Conversation Constitution
- Conversation Philosophy
- Conversation Blueprint

It adds no stages.
It invents no psychology system.
It only classifies which frozen Blueprint paths fit which emotional textures.

---

## Purpose

Blueprint already allows full arcs and compression.
Not every emotional night wants every spoken stage.

This taxonomy answers:

1. Which emotional categories naturally use the **full Blueprint**?
2. Which naturally use a **compressed Blueprint**?
3. Why compression differs by family
4. Which stages are naturally omitted (never forbidden by new law—only unused when compression serves rest)
5. How Blueprint law remains frozen while Golden Nights stay coherent

Emotional Conversation Families guide Golden Night authoring and Quality Lab selection.
They do not authorize new stages, solving, or backward motion.

---

## Frozen Law Reminder

From Conversation Blueprint (unchanged):

1. Arrival first; user speaks first
2. Receipt precedes every other spoken move
3. Skipping forward is allowed; moving backward is not
4. Rest is the only successful destination
5. Compression succeeds when it shortens the path to rest
6. Compression fails when it skips Receipt or reintroduces solving

This taxonomy only **selects among already-allowed shapes**.
It does not amend Blueprint.

---

## Family Definition

An Emotional Conversation Family is a group of nights that share:

1. A primary emotional texture at Arrival→first speech
2. A characteristic relationship to “setting something down”
3. A natural spoken-stage budget under frozen Blueprint compression rules

Families are for taxonomy and benchmark design.
They are not HCOS protocol owners and not new cognitive stages.

---

## The Families

### Family A — Active Mental Load

**Texture**  
The mind is busy with unfinished cognitive residue: loops, replaying, task pressure, rumination that feels like work still running.

**Seed nights**  
- GN-001 Overthinking Before Sleep

**Natural Blueprint use**  
**Full arc preferred**

```
Arrival → Receipt → Naming → Permission → Release → Enough → Rest
```

**Why full fits**  
The load is holdable and unloadable. Naming makes the loop graspable. Permission removes the duty to finish thinking. Release invites putting the mental work down. Enough closes speech cleanly.

**Naturally omitted**  
Usually none. Optional light compression only when readiness is already high:

- omit Naming if the person already named it themselves
- omit Enough speech if Release lands into silence (allowed compressed shapes only)

**Compression default**  
Low. Full is the home shape.

---

### Family B — Anticipatory Threat

**Texture**  
Dread pointed forward: what-ifs, next week, outcomes not yet real, body braced for a future that feels already pressing in.

**Seed nights**  
- GN-002 Future Anxiety Before Sleep

**Natural Blueprint use**  
**Full arc preferred**; short full or near-full compression acceptable

```
Arrival → Receipt → Naming → Permission → Release → Enough → Rest
```

Also natural when readiness rises quickly:

```
Arrival → Receipt → Naming → Permission → Enough → Rest
Arrival → Receipt → Permission → Release → Enough → Rest
```

**Why full / near-full fits**  
The future-threat is still a mental object that can be received, lightly named (“what’s coming”), and released from tonight’s duty. Permission matters: the night is not for solving the future. Release softens grip on forecast.

**Naturally omitted**
- Naming — when the person already states the future-threat clearly and naming would only repeat
- Release — when Permission alone unbraces the body and speech is already enough
- Never Receipt

**Compression default**  
Medium-low. Prefer keeping Permission. Prefer keeping Naming when the threat is diffuse.

---

### Family C — Relational Absence

**Texture**  
Missing someone; ache of presence wanted; quiet hollow; longing; attachment residue. Not a puzzle to solve and not primarily a forecast.

**Seed nights**  
- GN-003 Missing Someone Before Sleep

**Natural Blueprint use**  
**Compressed arc preferred**

Primary home shapes:

```
Arrival → Receipt → Enough → Rest
Arrival → Receipt → Permission → Enough → Rest
```

Secondary (when a soft name truly helps and stays light):

```
Arrival → Receipt → Naming → Enough → Rest
Arrival → Receipt → Naming → Permission → Enough → Rest
```

**Why compression fits**  
Longing is not unloadable work. Heavy Release (“set this down / let it rest”) can feel like putting the person down. “Solve this tonight” Permission framing misfits non-solvable ache. The emotional job is accurate witness and clean Enough—not a full unload sequence.

**Naturally omitted**
- Release — default omit for this family
- Naming — omit unless one soft, evident name deepens recognition without excavation
- Full Permission→Release chain — omit; if Permission appears, it authorizes unfinished longing for tonight without problem-solving tone (wording is style/Intelligence later; taxonomy only omits stages)
- Never Receipt
- Never skip to Rest without Receipt if any assistant speech occurs

**Compression default**  
High. Full arc is lawful but usually lower Human Gold for this family.

---

### Family D — Diffuse Unease

**Texture**  
Quiet wrongness without a clear object: “I don’t know what it is,” restlessness, vague heaviness, unnamed static.

**Seed nights**  
(none yet; reserved for future Golden Nights)

**Natural Blueprint use**  
**Compressed, Naming-cautious**

```
Arrival → Receipt → Enough → Rest
Arrival → Receipt → Permission → Enough → Rest
```

If something becomes nameable without digging:

```
Arrival → Receipt → Naming → Permission → Enough → Rest
```

**Why compression fits**  
There may be nothing stable to Release. Premature Naming risks inventing a load. Receipt + Permission/Enough often serve rest better than a full unload.

**Naturally omitted**
- Release — often omit (nothing clear to set down)
- Naming — omit until evident; never invent
- Never Receipt

**Compression default**  
High.

---

### Family E — High-Readiness Soft Landing

**Texture**  
Person already near rest; brief residue; little need for speech; may only need to be received once.

**Seed nights**  
(none yet; reserved)

**Natural Blueprint use**  
**Maximum lawful compression**

```
Arrival → Receipt → Enough → Rest
Arrival → Receipt → Permission → Rest
Arrival → Receipt → Release → Rest
```

**Why compression fits**  
Blueprint already names this: high readiness → fewer spoken stages. Extra stages add load.

**Naturally omitted**
- Naming, and often Permission or Release (keep only one soft mid-stage at most)
- Prefer the shortest restward path that still includes Receipt

**Compression default**  
Maximum.

---

### Family F — Mixed Residue (Secondary)

**Texture**  
Two textures present (e.g. missing someone *and* tomorrow’s pressure). One is primary.

**Natural Blueprint use**  
Follow the **primary** family’s default. Do not stack stages to cover both textures.

**Rule**  
One night, one family home shape. Mixed content does not justify backward motion or stage repetition.

## Why Families Compress Differently

Compression is not about importance.
It is about **whether the texture is something the night can set down**.

| If the texture is… | Compression tends to… | Because… |
|---|---|---|
| A mental object that can be held and put down | Stay fuller | Naming / Permission / Release each earn their keep |
| A forecast the mind is gripping | Stay fuller, keep Permission | Duty to solve the future must loosen |
| A person-shaped absence | Compress; spare Release | Setting-down language can wound recognition |
| Objectless unease | Compress; spare early Naming | Naming risks invention |
| Already soft | Compress hard | Extra speech is cost |

This is selection among frozen paths—not new emotional doctrine.

## Stages Naturally Omitted (By Family)

Omission means “not used in the family’s default golden shape.”
Omitted stages remain valid Blueprint stages elsewhere.

| Stage | A Load | B Threat | C Absence | D Diffuse | E Soft Landing |
|---|---|---|---|---|---|
| Arrival | required | required | required | required | required |
| Receipt | required | required | required | required | required |
| Naming | usual | usual / optional | optional | rare | rare |
| Permission | usual | usual | optional | optional | optional |
| Release | usual | optional | **usually omit** | **usually omit** | optional single mid-stage |
| Enough | usual | usual | usual (spoken or via silence after last stage per allowed shapes) | usual | optional per allowed shapes |
| Rest | required | required | required | required | required |

Enough may be spoken or the night may end on an allowed compressed terminal (e.g. Permission → Rest) exactly as Blueprint/Golden Night Specification already permit.

---

## How Blueprint Law Remains Frozen

1. **No new stages** are introduced by families.
2. **No stage is banned** from the product—families only recommend defaults for taxonomy and Golden authoring.
3. Every family shape listed here is already an **allowed** full or compressed arc under Blueprint + Golden Night Specification.
4. Universal laws still bind every family: Receipt-first, forward-only, Rest destination, no solving stages.
5. Constitution and Philosophy still bind every family: restward, received first, night not for solving, less is faithful.
6. If a night needs a shape outside allowed arcs, it is invalid—families cannot authorize it.
7. HCOS ownership is untouched; families do not decide release/protocol/exit.

**Hard rule**  
Families classify nights.
Blueprint still governs nights.

## Derivation Rule

A future Golden Night or Lab decision is family-aligned only if:

1. It picks an already-allowed Blueprint shape
2. It matches the family’s compression default unless readiness clearly differs
3. It never skips Receipt when speech occurs
4. It never adds stages or doctrine to justify the night

If a proposed family behavior needs a new Blueprint stage, it is rejected.
If it only chooses among frozen paths, it belongs here.
