# NOCTA EMOTIONAL PATTERN LIBRARY V1

---

# PURPOSE

This document defines every Emotional Pattern that HCOS V1 is capable of recognizing.

Emotional Patterns represent recurring emotional states observed across conversations.

They are detected from accumulated evidence rather than isolated keywords.


---

# EMOTIONAL PATTERN 001

Name

Anxiety

Description

A recurring emotional state characterized by uncertainty, anticipation of negative outcomes and heightened vigilance.

Recognition Signals

- Worrying about the future
- Fear of uncertainty
- Feeling on edge
- Difficulty relaxing
- Persistent concern

Examples

- What if something goes wrong?
- I feel anxious.
- I can't relax.
- I'm worried about tomorrow.
- My chest feels tight because I'm overthinking.
