# NOCTA EMOTIONAL PATTERN V1

---

# PURPOSE

An Emotional Pattern represents a recurring emotional response that repeatedly appears across different conversations and situations.

It is not a temporary emotion.

It is not a diagnosis.

It represents an emotional tendency that becomes visible over time.


---

# DEFINITION

An Emotional Pattern is a stable emotional tendency that repeatedly appears across different conversations and situations.

It describes how the user typically responds emotionally rather than how the user feels in a single moment.

Emotional Patterns evolve over time as new evidence is collected.
