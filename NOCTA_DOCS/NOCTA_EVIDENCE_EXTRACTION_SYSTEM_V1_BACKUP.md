# PURPOSE

The Evidence Extraction System identifies and organizes all observable evidence contained in the user's message.

Its responsibility is to transform raw user input into structured evidence that can be used by downstream AI systems.

The system does not interpret evidence.

It does not assign Mental States.

It does not detect Sleep Barriers.

It only extracts evidence.

"What observable evidence exists in the user's message?"

# EVIDENCE DEFINITION

Evidence is any observable information extracted directly from the user's message.

Evidence must be based only on what the user communicates.

Evidence is never assumed.

Evidence is never inferred without support.

Evidence represents facts observed in the user's language, context, cognition, emotions, or behavior.

Every downstream AI system operates using Evidence rather than raw user messages.

# END OF PART 2

# EVIDENCE OBJECT

The output of the Evidence Extraction System is a structured Evidence Object.

The Evidence Object contains:

- Language Evidence
- Context Evidence
- Cognitive Evidence
- Emotional Evidence
- Behavioral Evidence

Every downstream AI system consumes the Evidence Object instead of the raw user message.

# END OF PART 3


---

# PART 4 — EXTRACTION PROCESS

The Evidence Extraction System follows a deterministic extraction process.

Step 1

Read the complete user message without interpretation.

Step 2

Identify all observable evidence contained in the message.

Step 3

Classify each piece of evidence into the appropriate Evidence Category.

Step 4

Combine all classified evidence into a single Evidence Object.

Step 5

Deliver the Evidence Object to downstream AI systems.

The Evidence Extraction System never interprets, diagnoses or generates responses.

It only extracts and organizes observable evidence.

# PART 5 — EVIDENCE CATEGORIES

The Evidence Extraction System classifies every piece of evidence into one of the following categories.

## Language Evidence

Observable words, phrases and linguistic patterns.

## Context Evidence

The life situation or domain discussed by the user.

Examples:

- Work
- Relationships
- Health
- Family
- Finance

## Cognitive Evidence

Observable thinking patterns.

Examples:

- Repetitive thinking
- Catastrophic thinking
- Control seeking
- Uncertainty

## Emotional Evidence

Observable emotional signals.

Examples:

- Fear
- Sadness
- Guilt
- Anger
- Loneliness

## Behavioral Evidence

Observable behaviors or functional difficulties.

Examples:

- Unable to sleep
- Avoidance
- Constant checking
- Mental exhaustion
