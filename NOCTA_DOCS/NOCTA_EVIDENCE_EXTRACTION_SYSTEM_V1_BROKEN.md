# PART 1 — PURPOSE

The Evidence Extraction System is responsible for transforming a raw user message into structured, observable evidence.

It serves as the foundation for all downstream AI systems.

Its purpose is to identify only what is explicitly supported by the user's message, without making interpretations or assumptions.

The system extracts evidence that can be reliably consumed by later modules such as:

- Mental State Detection
- Sleep Barrier Detection
- Conversation Strategy
- Audio Intelligence

The Evidence Extraction System never diagnoses, predicts or generates responses.

Its only responsibility is to produce a structured Evidence Object that accurately represents the observable information contained in the user's message.
