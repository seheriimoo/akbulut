# NOCTA FAILURE CASES V1

## PURPOSE

This document identifies ambiguous, difficult and potentially misclassified user messages.

The goal is to improve:

- Category Detection
- Insight Selection
- Mental State Detection
- Audio Selection

---

# CASE 01

USER MESSAGE:

I'm tired.

RISK:

Could be:

- Work Stress
- Emotional Pain
- Exhaustion
- Physical Fatigue

PROBLEM:

Insufficient information.

---

# CASE 02

USER MESSAGE:

I don't know.

RISK:

Could be:

- Overthinking
- Emotional Pain
- Relationship
- Loneliness

PROBLEM:

No clear signal.

---

# CASE 03

USER MESSAGE:

Everything feels wrong.

RISK:

Could be:

- Emotional Pain
- Future Anxiety
- Relationship
- Work Stress

PROBLEM:

Multiple categories possible.

---

# CASE 04

USER MESSAGE:

I just want this feeling to stop.

RISK:

Emotional state is clear.

Source is unclear.

PROBLEM:

Category ambiguity.

---

# CASE 05

USER MESSAGE:

I can't do this anymore.

RISK:

High emotional intensity.

Could belong to multiple categories.

PROBLEM:

Requires special handling.
