# NOCTA FALLBACK ROUTING V1

## PURPOSE

This document defines default routing behavior when user messages are ambiguous, vague or difficult to classify.

The goal is to maintain a smooth sleep transition experience without forcing incorrect categorization.

---

# FALLBACK 01

USER MESSAGE:

I'm tired.

DEFAULT CATEGORY:

Work Stress

DEFAULT MENTAL STATE:

Exhaustion

DEFAULT AUDIO:

Deep Rest

RATIONALE:

Fatigue is usually best served by restoration rather than analysis.

---

# FALLBACK 02

USER MESSAGE:

I don't know.

DEFAULT CATEGORY:

Emotional Pain

DEFAULT MENTAL STATE:

Emotional Weight

DEFAULT AUDIO:

Safety & Comfort

RATIONALE:

The user is expressing uncertainty rather than a specific problem.
