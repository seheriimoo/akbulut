# NOCTA INSIGHT ROUTING V2

## PURPOSE

Determine the most relevant insight behind a user message.

V1 used a simple:

User Message
→ Insight

approach.

V2 introduces:

User Message
→ Category
→ Primary Insight
→ Secondary Insight
→ Reframe Direction

This allows more accurate emotional understanding.

---

## ROUTING STRUCTURE

### Category

The dominant emotional category detected from the user message.

Examples:

- Overthinking
- Future Anxiety
- Relationship
- Loneliness
- Emotional Pain
- Work Stress

---

### Primary Insight

The strongest psychological pattern present.

This insight should drive the response.

---

### Secondary Insight

A supporting psychological pattern.

Used only when relevant.

Not required for every message.

---

### Reframe Direction

The perspective shift that should occur.

Examples:

- Future Burden
- Letting Go
- Emotional Acceptance
- Reducing Mental Load
- Releasing Control
- Self Compassion

---
