# NOCTA LEARNING ENGINE V1

---

# PURPOSE

The Learning Engine continuously improves the Living Mind Model.

Its purpose is not to detect Mental Patterns.

Its purpose is to update confidence, observations and long-term understanding based on accumulated evidence.


---

# LEARNING RULES

The Learning Engine follows four rules.

1. If a Mental Pattern has never been observed before, create it.

2. If the Mental Pattern already exists, increase its observation count.

3. Increase confidence only when new evidence supports the same pattern.

4. Update the pattern status based on accumulated evidence.


---

# LEARNING WORKFLOW

For every detected Mental Pattern, the Learning Engine performs the following steps.

1. Search the Living Mind Model for an existing Mental Pattern.

2. If none exists, create a new Mental Pattern.

3. If one exists, merge the new evidence with the existing pattern.

4. Update confidence.

5. Update observation count.

6. Update pattern status.

7. Save the updated Living Mind Model.
