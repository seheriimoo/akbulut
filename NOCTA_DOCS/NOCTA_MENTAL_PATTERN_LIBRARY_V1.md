# NOCTA MENTAL PATTERN LIBRARY V1

---

# PURPOSE

This document defines every Mental Pattern that HCOS V1 is capable of recognizing.

Mental Patterns are stable cognitive tendencies observed over time.

They are used by the Mental Pattern Detector to identify recurring thinking processes.


---

# PATTERN 001

Name

Overanalyzing

Description

The user repeatedly attempts to solve, predict or mentally simulate situations instead of allowing uncertainty.

Recognition Signals

- Repeated analysis
- Endless thinking
- Mental simulation
- Difficulty letting go
- Searching for certainty


Examples

- I can't stop thinking.
- My mind won't switch off.
- I keep replaying the same situation.
- What if this happens?
- I analyze everything before I sleep.
