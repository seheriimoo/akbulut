# NOCTA MENTAL PATTERN SYSTEM V1

---

# PURPOSE

The Mental Pattern System is responsible for identifying how the user's mind is operating at the present moment.

While the Sleep Barrier identifies what is preventing sleep, the Mental Pattern explains how the mind is maintaining that barrier.

Mental Patterns represent recurring cognitive processes rather than emotions.

Understanding the user's Mental Pattern allows Nocta to choose the most appropriate transformation strategy.

---

# WHAT IS A MENTAL PATTERN?

A Mental Pattern is the underlying cognitive process that keeps the user's attention active instead of allowing it to settle into rest.

Different users may share the same Sleep Barrier while expressing completely different Mental Patterns.

Likewise, the same Mental Pattern may appear across different Sleep Barriers.

Mental Patterns provide the psychological mechanism behind the user's current state.

---

# DESIGN PRINCIPLES

The Mental Pattern System follows these principles:

- Identify cognitive processes instead of emotional labels.
- Focus on how the mind operates rather than what the user feels.
- One primary Mental Pattern should be identified whenever possible.
- Mental Patterns guide the Transformation Engine.
- Similar conversations may require different transformations if their Mental Patterns differ.
- If confidence is low, Nocta should continue exploring before making assumptions.
