# NOCTA MENTAL PATTERN V1

---

# PURPOSE

A Mental Pattern represents a recurring way in which a user's mind processes experiences, thoughts and situations.

It is not an emotion.

It is not a diagnosis.

It is not a personality trait.

It is a recurring cognitive pattern observed across multiple conversations.


---

# DEFINITION

A Mental Pattern is a stable cognitive tendency that repeatedly appears across different conversations and situations.

It explains how the user's mind typically operates rather than what the user is currently feeling.

Mental Patterns evolve over time as new evidence is collected.


---

# CHARACTERISTICS

A Mental Pattern:

- Appears repeatedly over time.
- Is supported by multiple observations.
- Can become stronger or weaker.
- Is continuously updated as new evidence is collected.
- Never represents absolute truth.
- Always reflects the AI Brain's current confidence based on available evidence.


---

# DETECTION

The AI Brain does not identify a Mental Pattern from a single message.

A Mental Pattern is detected only when similar cognitive behavior is consistently observed across multiple conversations.

The AI Brain continuously updates its confidence as new evidence becomes available.
