# NOCTA MENTAL PROCESS ENGINE V1

---

# PURPOSE

The Mental Process Engine identifies the active cognitive process currently running in the user's mind.

It does not detect emotions.

It does not detect topics.

It identifies what the user's mind is actively trying to do.


---

# PRINCIPLES

A Mental Process is not:

- An emotion
- A topic
- A diagnosis
- A personality trait
- A life event

A Mental Process is the active cognitive operation currently running in the user's mind.


---

# DECISION FACTORS

The Mental Process Engine identifies the active mental process by evaluating:

- What the user is mentally focusing on
- What the user's mind is repeatedly trying to accomplish
- What type of cognitive activity is dominating the message
- What prevents the user's mind from naturally disengaging


---

# CLASSIFICATION RULES

A Mental Process must:

- Describe a cognitive operation
- Be independent of any specific topic
- Be independent of any emotion
- Be observable through language
- Lead to different conversational strategies


---

# THEORY

Every conscious thought is produced by an active mental process.

A Mental Process is the cognitive operation that transforms an experience into thoughts, emotions and behaviors.

Nocta identifies this process before attempting to guide the user.
