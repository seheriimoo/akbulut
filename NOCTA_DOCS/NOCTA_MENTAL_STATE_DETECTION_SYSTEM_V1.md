# PART 1 — PURPOSE

The Mental State Detection System is responsible for identifying the user's current Mental State based exclusively on the Evidence Object produced by the Evidence Extraction System.

Its purpose is to convert structured evidence into a standardized Mental State Object.

The system does not analyze the Raw User Message directly.

Instead, it evaluates observable evidence and determines which Mental State is best supported.

The output of this system provides the psychological context required by downstream AI systems.

The Mental State Detection System never generates responses, recommends audio, detects Sleep Barriers or performs therapeutic reasoning.
