# NOCTA MENTAL STATE ENGINE V1

## PURPOSE

This document defines how Nocta identifies the user's mental state.

Categories explain the topic.

Mental states explain the experience.

Mental states are used for audio selection.

---

# DETECTION FLOW

User Message
↓
Category Detection
↓
Insight Selection
↓
Mental State Detection
↓
Audio Selection

---

# MENTAL STATE 01 — MENTAL ACTIVATION

Description:

The mind remains highly active.

Common Signs:

- Racing thoughts
- Mental loops
- Constant analysis
- Difficulty slowing down

Primary Audio Route:

Mental Quieting

---

# MENTAL STATE 02 — CONTROL SEEKING

Description:

The mind is attempting to gain certainty or control.

Common Signs:

- Over-planning
- Need for answers
- Perfectionism
- Over-analysis

Primary Audio Route:

Letting Go

---

# MENTAL STATE 03 — EMOTIONAL WEIGHT

Description:

The user is carrying unresolved emotional pain.

Common Signs:

- Sadness
- Regret
- Heartbreak
- Guilt

Primary Audio Route:

Emotional Release

---

# MENTAL STATE 04 — DISCONNECTION

Description:

The user feels emotionally disconnected.

Common Signs:

- Loneliness
- Feeling unseen
- Lack of connection
- Isolation

Primary Audio Route:

Safety & Comfort

---

# MENTAL STATE 05 — EXHAUSTION

Description:

The user has depleted emotional or physical resources.

Common Signs:

- Burnout
- Fatigue
- Work overload
- Running on empty

Primary Audio Route:

Deep Rest

---

# MENTAL STATE 06 — FUTURE PRESSURE

Description:

The user is carrying future-oriented stress.

Common Signs:

- What-if thinking
- Tomorrow anxiety
- Upcoming events
- Uncertainty

Primary Audio Route:

Future Release
