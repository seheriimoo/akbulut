# NOCTA MESSAGE UNDERSTANDING ENGINE V1

---

# PURPOSE

The Message Understanding Engine extracts the objective meaning of the user's message.

It does not perform psychological analysis.

It only determines what the user is talking about.


---

# OUTPUT

The Message Understanding Engine extracts the following information:

- Topic
- Primary Subject
- Time Reference
- People
- Events
- Objects
- Message Summary


---

# INPUT

Input:

- Raw user message
