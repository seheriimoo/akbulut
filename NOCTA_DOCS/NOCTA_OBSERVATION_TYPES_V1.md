# NOCTA OBSERVATION TYPES V1

---

# PURPOSE

This document defines the different observation types that Nocta can detect before generating its first response.

A SleepState is too broad.

Each SleepState contains multiple psychological experiences.

The Observe Engine must first identify the Observation Type.

Only then should it generate an observation.

---

# STRUCTURE

SleepState
    ↓
Observation Type
    ↓
Observe Response


---

# OVERTHINKING

## Observation Types

### Racing Thoughts

The user's thoughts are moving too quickly to settle.

---

### Looping Thoughts

The user's mind keeps returning to the same thought repeatedly.

---

### Endless Analysis

The user is continuously analyzing without reaching a conclusion.

---

### Decision Fatigue

The user feels mentally exhausted from trying to make the right decision.

---

### What-if Thinking

The user's attention is focused on possible future scenarios and their consequences.

---

### Mental Overload

The user feels that too many thoughts are competing for attention at once.

---

### Hypervigilance

The user's mind remains alert, scanning for potential problems even when trying to rest.
