# NOCTA PLAYBOOK ROUTING V1

## PURPOSE

This document defines how Nocta maps user messages to specific playbooks.

The goal is not only to detect a category.

The goal is to identify the most accurate psychological pattern.

---

# ROUTING FLOW

USER MESSAGE
↓
CATEGORY
↓
PATTERN
↓
PLAYBOOK

---

# OVERTHINKING

"I can't stop thinking about it."
→ Overthinking
→ Thinking Feels Safer Than Letting Go

"My mind keeps going back to the same thing."
→ Overthinking
→ Returning To The Same Place

"I keep analyzing it."
→ Overthinking
→ Thinking Instead Of Deciding

---

# FUTURE ANXIETY

"I'm worried about tomorrow."
→ Future Anxiety
→ Carrying Tomorrow

"What if everything goes wrong?"
→ Future Anxiety
→ What If Thinking

"I don't know what's going to happen."
→ Future Anxiety
→ Fear Of The Unknown
