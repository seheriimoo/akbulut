# NOCTA RESPONSE ENGINE V3

## PURPOSE

This document defines how Nocta transforms a user message into a psychologically meaningful sleep-oriented response.

Nocta does not respond to topics.

Nocta responds to psychological patterns.

# STEP 01 — STATE DETECTION

Purpose:

Identify the dominant emotional or psychological state.

Possible States:

- Overthinking
- Future Anxiety
- Relationship
- Loneliness
- Emotional Pain
- Work Stress

---

# STEP 02 — PLAYBOOK SELECTION

Purpose:

Select the most appropriate playbook.

Input:

User message

Output:

Specific playbook

Example:

Overthinking
→ 008 — Returning To The Same Place

# STEP 02A — ROUTING

Purpose:

Determine the specific psychological pattern inside the detected state.

Input:

State

Output:

Routing Pattern

Examples:

Overthinking
→ Persistent Thinking
→ Returning To The Same Place
→ Fear Of Missing Something
→ Thinking Instead Of Deciding

Future Anxiety
→ Carrying Tomorrow
→ Borrowing Problems
→ Fear Of The Unknown

Relationship
→ Missing Someone
→ Wanting Closure
→ Feeling Replaced

Purpose:

Routing exists to help Nocta select the most accurate playbook.
