# NOCTA RETENTION ENGINE V1

## PURPOSE

This document defines how Nocta creates long-term user retention.

The goal is not simply to help the user sleep once.

The goal is to become part of the user's nightly routine.

---

# RETENTION PHILOSOPHY

People do not return because they were helped.

People return because they felt understood.

People do not build habits with tools.

People build habits with experiences.

---

# RETENTION GOAL

Night 1

The user feels understood.

Night 2

The user remembers Nocta.

Night 7

The user trusts Nocta.

Night 30

The user feels strange going to sleep without Nocta.


---

# CRITICAL RETENTION WINDOW

The most important retention period is not Night 30.

The most important retention period is:

Night 2
Night 3
Night 4

This is where habits begin or disappear.

---

# USER JOURNEY

Night 1

"I feel understood."

Night 2

"I want to talk again."

Night 3

"I wonder what Nocta will say tonight."

Night 4

"Opening Nocta starts to feel natural."

Night 7

"This is becoming part of my routine."

Night 30

"Going to sleep without Nocta feels unusual."
