# OVERTHINKING

## 001 — Thinking Feels Safer Than Letting Go

Primary Signals:

- can't stop thinking
- mind won't switch off
- keep thinking about it
- unable to let go
- thinking feels necessary
- afraid to stop thinking

Route When:

The user describes persistent thinking without a more specific pattern.

Do Not Route When:

- the user is clearly searching for a perfect answer
- the user is stuck between choices
- the user repeatedly returns to one specific subject
- the user fears missing an important detail

---

## 002 — One More Thought

Primary Signals:

- one more thought
- one more idea
- almost figured it out
- just need to think a little longer
- relief feels close
- answer feels one thought away

Route When:

The user believes one final thought or analysis will bring relief.

Do Not Route When:

The user is broadly unable to stop thinking without expecting an immediate answer.

---

## 003 — Unfinished Mental Loops

Primary Signals:

- unfinished
- unresolved
- incomplete
- loose ends
- something still feels open
- can't close the loop

Route When:

The mind keeps returning because something feels incomplete or unresolved.

Do Not Route When:

The user is primarily comparing options or searching for certainty.

---

## 004 — Searching For The Perfect Answer

Primary Signals:

- perfect answer
- right answer
- best option
- analyzing every possibility
- need to be completely sure
- afraid of choosing incorrectly

Route When:

The user is overanalyzing because they believe a perfect answer exists.

Do Not Route When:

The user is only postponing a decision without searching for perfection.

---

## 005 — Thinking As Preparation

Primary Signals:

- need to be prepared
- rehearsing everything
- planning every possibility
- thinking ahead
- preparing for what might happen
- don't want to be caught off guard

Route When:

The user uses thinking as protection against feeling unprepared.

Do Not Route When:

The concern is mainly about a specific future event rather than the thinking process itself.

---

## 006 — Fear Of Missing Something

Primary Signals:

- what if I missed something
- forgetting something important
- overlooking a detail
- need to check again
- something might be missing
- can't stop reviewing

Route When:

The user keeps thinking because they fear overlooking important information.

Do Not Route When:

The user is searching for the best possible answer rather than checking for omissions.

---

## 007 — Thinking Instead Of Deciding

Primary Signals:

- can't decide
- stuck between options
- keep delaying the decision
- don't know what to choose
- afraid to commit
- thinking instead of acting

Route When:

Thinking is replacing a decision or action.

Do Not Route When:

The user has already decided but keeps mentally revisiting the subject.

---

## 008 — Returning To The Same Place

Primary Signals:

- keep coming back to it
- same thought again
- mind returns to the same thing
- going in circles
- replaying the same subject
- back where I started

Route When:

The user repeatedly returns to the same thought, memory or question.

Do Not Route When:

The main issue is an incomplete task or unresolved practical problem.

---

## 009 — Mistaking Thinking For Progress

Primary Signals:

- thinking feels productive
- feel like I'm doing something
- analyzing but getting nowhere
- thinking instead of moving forward
- confusing reflection with progress
- nothing changes despite thinking

Route When:

The user treats continued thinking as if it were meaningful progress.

Do Not Route When:

The user is actively trying to make a concrete decision.

---

## 010 — The Search Never Ends

Primary Signals:

- no answer is enough
- every answer creates another question
- keep searching
- can't reach certainty
- endless analysis
- the search never stops

Route When:

The user continues searching even after receiving possible answers.

Do Not Route When:

The user is simply waiting for one final answer or insight.

---

## OVERTHINKING ROUTING PRIORITY

Use the most specific matching playbook.

Priority Order:

1. Specific behavioral pattern
2. Specific fear or belief
3. General overthinking pattern

Fallback:

If no specific subtype is clear, route to:

001 — Thinking Feels Safer Than Letting Go
