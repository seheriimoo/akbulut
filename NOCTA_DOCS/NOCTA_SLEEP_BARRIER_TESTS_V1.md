# NOCTA SLEEP BARRIER TESTS V1

---

# PURPOSE

This document validates whether the Nocta Sleep Barrier System can consistently identify the correct primary barrier from real user messages.

Each test case includes:

- User Message
- Expected Sleep Barrier
- Why this barrier should be selected
- Possible competing barriers

The purpose is to improve the accuracy and consistency of the AI before expanding the knowledge base.

---

# TEST CASES

## TEST 001

### User Message

I can't stop thinking about the same conversation over and over again.

### Expected Barrier

Overthinking

### Why

The user's attention repeatedly returns to the same unresolved topic rather than shifting toward future uncertainty.

### Possible Competing Barriers

- Relationship Distress
