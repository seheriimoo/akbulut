# PSYCHOLOGICAL ANALYSIS ENGINE V1

---

# PURPOSE

The Psychological Analysis Engine is responsible for understanding the user's mind before any response is generated.

It does not generate responses.

It generates understanding.

---

# OUTPUT

Every user message should be analyzed into the following structure.

Psychological Analysis

- Sleep State
- Observation Type
- Emotional Tone
- Intensity
- Core Need
- Sleep Barrier
- Conversation Stage
- Risk Level
